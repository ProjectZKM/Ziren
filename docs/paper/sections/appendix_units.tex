\section{The instruction frame and the chips}
\label{sec:app-chips}
\label{sec:app-frame}

Table~\ref{tab:frame} itemises the columns of the instruction frame. The R-type frame raises 20 interactions per row: one program fetch; a receive of $(\mathsf{shard}, \mathsf{clk}, \mathsf{pc}, \mathsf{next\_pc})$ and a send of $(\mathsf{shard}, \mathsf{clk} + 5 + \delta, \mathsf{next\_pc}, \mathsf{next\_next\_pc})$ on the state bus, where $\delta$ is zero except for a system call; a send of the previous and a receive of the new tuple on the memory bus for each of its three accesses; and eleven table lookups, one 16-bit check of the shard, two for the clock limbs, two per access for the timestamp difference, and two for the four bytes of the written word, which the byte table checks in pairs. The I-type and shift-amount frames have one access fewer, and raise 16. Tables~\ref{tab:chips} and~\ref{tab:chips-other} list the chips.
