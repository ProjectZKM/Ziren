\section{Recursion}
\label{sec:recursion}

Shard proofs are aggregated by a recursion machine: a small register VM over the same field whose programs are compiled from a description of the verifier, executed to a trace, and proved by the same chip/\LogUp{}/zerocheck/Jagged/\WHIR{} pipeline. Its chips are the arithmetic of $\F$ and $\EF$, memory, the $\Poseidon{}$ permutation, a select gate and a batched folding gate for the FRI-style query checks. The root of the tree it builds is the compressed proof; the verifying-key allowlist binds that proof to the advertised machine.

\paragraph{Leaves.} A \emph{leaf} (\emph{normalize}) program verifies one core shard proof in four phases mirroring the host verifier: the transcript prologue (public values, commitment, chip dimensions), the \LogUp{} layer replay, the zerocheck replay with the constraint evaluation of every chip present, and the jagged opening with its closing identity followed by the \WHIR{} verifier. The jagged verifier depends only on the shard's two geometry buckets and the constraint evaluation only on its chip set and whether it is the first shard, so the leaf programs form a bounded set that can be enumerated in advance; on one GPU, consecutive shards of the same class reuse a device-resident proving key. Adjacent leaves are \emph{fused} into one node where shapes allow, and leaves are proved on the same GPU concurrently with core shards. Figure~\ref{fig:recursion} shows the tree.

\paragraph{The compose relation.} Write a node's public values as
\[
  \mathsf{pv} = (\mathsf{vk}, \mathsf{sh}_{\mathrm{in}}, \mathsf{sh}_{\mathrm{out}}, \mathsf{entry}, \mathsf{exit}, \mathsf{cur}_{\mathrm{in}}, \mathsf{cur}_{\mathrm{out}}, D, h, \mathsf{code}, \mathsf{root}),
\]
the guest's verifying key, the index of the node's first shard and the index after its last, the entry and exit machine states, the memory-address cursors the node opens and closes with, the accumulated cross-shard digest, the digest of committed output, the exit code, and the root of the allowlist of admissible recursion keys; a completion flag $\mathsf{complete}$, set only by the root, accompanies the tuple. With a delay slot the entry and exit states are \emph{pairs} $(\mathsf{pc}, \mathsf{pc}_{\mathrm{next}})$, so adjacency must pin both components. A compose node of arity $k$ proves $\mathcal R_{\mathrm{comp}}(\mathsf{pv}; \pi_0,\dots,\pi_{k-1})$, which holds when each $\pi_i$ verifies against a key the allowlist at $\mathsf{root}$ contains; the children agree on $\mathsf{vk}$, $h$ and $\mathsf{code}$; every $\mathsf{root}_i$ equals the published $\mathsf{root}$; the ranges are adjacent, $\mathsf{sh}_{\mathrm{out},i} = \mathsf{sh}_{\mathrm{in},i+1}$, $\mathsf{exit}_i = \mathsf{entry}_{i+1}$ and $\mathsf{cur}_{\mathrm{out},i} = \mathsf{cur}_{\mathrm{in},i+1}$; and $\mathsf{sh}_{\mathrm{in}} = \mathsf{sh}_{\mathrm{in},0}$, $\mathsf{sh}_{\mathrm{out}} = \mathsf{sh}_{\mathrm{out},k-1}$, $\mathsf{entry} = \mathsf{entry}_0$, $\mathsf{exit} = \mathsf{exit}_{k-1}$, $\mathsf{cur}_{\mathrm{in}} = \mathsf{cur}_{\mathrm{in},0}$, $\mathsf{cur}_{\mathrm{out}} = \mathsf{cur}_{\mathrm{out},k-1}$ and $D = \sum_i D_i$. Digests are stored offset by the starting point $D_{\mathrm{off}}$ of \S\ref{sec:air-global}, so this sum is computed as $D_0 + D_1 - D_{\mathrm{off}}$ and so on, and $D = O$ below means the stored value equals $D_{\mathrm{off}}$.

\paragraph{Leaves and the root.} A leaf proves the same relation for its one or more fused children, except that each child is a core shard proof verified against the guest's $\mathsf{vk}$; it is the leaf's own key that the allowlist must contain, checked by its parent. A leaf sets $\mathsf{sh}_{\mathrm{in}}$ and $\mathsf{sh}_{\mathrm{out}}$ from the shard indices it verifies, and the leaf of the first shard, index~1, also requires its entry state to be $\mathsf{start}(\mathsf{vk})$, the start state the guest key fixes. The root additionally requires $\mathsf{sh}_{\mathrm{in}} = 1$, so its leftmost leaf is that first-shard leaf; an exit state with program counter zero, the halted state (\S\ref{sec:ext-syscall}); empty cursors, $D$ the identity and exit code zero; and it sets $\mathsf{complete}$, which closes the memory argument and the cross-shard digest over the execution and admits only the halts of Section~\ref{sec:statement}. Algorithm~\ref{alg:compose} states the checks.

\begin{algorithm}[t]
\caption{The compose node of arity $k$, and what the root additionally
requires. Line~2 is the binding of \S\ref{sec:security-binding}: without it the node
would verify \emph{some} proof rather than a proof of this machine.}
\label{alg:compose}
\DontPrintSemicolon
\KwIn{child proofs $\pi_0,\dots,\pi_{k-1}$ with public values
      $\mathsf{pv}_0,\dots,\mathsf{pv}_{k-1}$, recursion keys $\mathsf{vk}^{\mathrm{rec}}_0,\dots,\mathsf{vk}^{\mathrm{rec}}_{k-1}$ and membership paths
      $\mathsf{path}_0,\dots,\mathsf{path}_{k-1}$; a claimed allowlist root $\mathsf{root}$}
\KwOut{the node's public values $\mathsf{pv}$, or $\bot$}
\For{$i \gets 0$ \KwTo $k-1$}{
  \lIf{$\neg\,\mathsf{MerkleVerify}(\mathsf{root}, \mathsf{vk}^{\mathrm{rec}}_i, \mathsf{path}_i)$}{\Return $\bot$
    \tcp*[f]{the child's key is admissible}}
  \lIf{$\neg\,\mathsf{Verify}(\mathsf{vk}^{\mathrm{rec}}_i, \mathsf{pv}_i, \pi_i)$}{\Return $\bot$}
}
\lIf{$\exists\, i:\ \mathsf{root}_i \neq \mathsf{root}$}{\Return $\bot$
    \tcp*[f]{children agree with the root they were checked against}}
\lIf{$\mathsf{vk}_i$, $h_i$, $\mathsf{code}_i$ not all equal over $i$}{\Return $\bot$}
\For{$i \gets 0$ \KwTo $k-2$}{
  \lIf{$\mathsf{sh}_{\mathrm{out},i} \neq \mathsf{sh}_{\mathrm{in},i+1} \lor \mathsf{exit}_i \neq \mathsf{entry}_{i+1}$}{\Return $\bot$
    \tcp*[f]{ranges adjacent}}
  \lIf{$\mathsf{cur}_{\mathrm{out},i} \neq \mathsf{cur}_{\mathrm{in},i+1}$}{\Return $\bot$
    \tcp*[f]{cursors tile}}
}
$D \gets \sum_{i} D_i$ \tcp*{digests accumulate}
$\mathsf{pv} \gets (\mathsf{vk},\ \mathsf{sh}_{\mathrm{in},0},\ \mathsf{sh}_{\mathrm{out},k-1},\ \mathsf{entry}_0,\ \mathsf{exit}_{k-1},\
  \mathsf{cur}_{\mathrm{in},0},\ \mathsf{cur}_{\mathrm{out},k-1},\ D,\ h,\ \mathsf{code},\ \mathsf{root})$\;
\If{this node is the root}{
  \lIf{$\mathsf{sh}_{\mathrm{in}} \neq 1 \lor \mathsf{pc}(\mathsf{exit}) \neq 0$}{\Return $\bot$
    \tcp*[f]{starts at the first shard, halted}}
  \lIf{$\mathsf{cur}_{\mathrm{in}}, \mathsf{cur}_{\mathrm{out}}$ non-empty
       $\lor\ D \neq O \lor \mathsf{code} \neq 0$}{\Return $\bot$}
  set $\mathsf{complete}$\;
}
\Return $\mathsf{pv}$\;
\end{algorithm}

\paragraph{Tree shape.} The tree merges contiguous shard \emph{ranges} as soon as they are complete rather than level by level, which shortens the tail after the last core shard from four serial composes to two (\S\ref{sec:perf-pipeline}). A leaf is never the root: a single-shard execution closes through a compose of arity one, keeping leaf programs within the classes the enumeration below covers. Arity is capped at three by the recursion chips' height budget; arity four was measured as neutral (41 nodes replaced by 27, $-0.7\%$ of wall time, unchanged tail).

\paragraph{Verifying-key binding.} Each compose node checks its children's recursion keys against a Merkle allowlist whose root it exports as a public value; why that binds the proof to the advertised machine, and what the external verifier checks of the root, are explained in \S\ref{sec:security-binding}.

\paragraph{Enumerating the leaf keys.} A leaf program is determined by the geometry of the shard proof it verifies, which Section~\ref{sec:pcs-geometry} quantises into buckets with a padding-column count fixed by the bucket. What remains is the shard's chip set, one of the machine's declared clusters, whether it is the execution's first shard, and the two bucket indices. Enumerating those combinations yields, without running a guest, every leaf key a prover can produce for a shard in those clusters, at most $2\,|\mathcal C|\,|\mathcal B_{\mathrm{prep}}|\,|\mathcal B_{\mathrm{main}}|$ of them. A \emph{cluster} is a chip-set combination declared by the shape configuration, curated from the target workloads rather than exhaustive over the chip powerset, so the allowlist covers an arbitrary guest only as far as the list does (\S\ref{sec:scope}). A shard outside the list produces a key the allowlist lacks and is refused: a loud failure of completeness, not of soundness. For the configuration this paper describes, the allowlist holds 6\,366 leaf and compose keys.

Sampling the leaf keys from a corpus of proved shards instead would leave every shard shape the corpus missed outside the allowlist. The enumeration is checked against such a corpus class by class and against the programs the classes generate. Algorithm~\ref{alg:enum} states it; every quantity it ranges over is fixed by the machine and the committed geometry.

\begin{algorithm}[t]
\caption{Enumerating the admissible leaf and compose keys. The loop bounds come from the
machine's chip clusters and from the bucket rule of \S\ref{sec:pcs-geometry};
no guest is executed.}
\label{alg:enum}
\DontPrintSemicolon
\KwIn{chip clusters $\mathcal{C}$; bucket sets $\mathcal{B}_{\mathrm{prep}}$,
      $\mathcal{B}_{\mathrm{main}}$; padding rule $\mathsf{pad}(\cdot)$}
\KwOut{the allowlist root $\mathsf{root}$}
$K \gets \emptyset$\;
\ForEach{cluster $c \in \mathcal{C}$}{
  \ForEach{$b_{\mathrm{p}} \in \mathcal{B}_{\mathrm{prep}}$,
           $b_{\mathrm{m}} \in \mathcal{B}_{\mathrm{main}}$}{
    $n \gets \mathsf{pad}(b_{\mathrm{m}})$ \tcp*{a function of the bucket, not of the real count}
    \ForEach{$\mathit{first} \in \{\mathsf{true}, \mathsf{false}\}$}{
      $\sigma \gets (c,\ \mathit{first},\ b_{\mathrm{p}},\ b_{\mathrm{m}},\ n)$
        \tcp*{the shape a leaf can be asked to verify}
      $K \gets K \cup \{\,\mathsf{vk}(\mathsf{CompileLeaf}(\sigma))\,\}$\;
    }
  }
}
\ForEach{compose shape $\gamma$ (arity $k \le 3$ over the leaf and compose classes)}{
  $K \gets K \cup \{\,\mathsf{vk}(\mathsf{CompileCompose}(\gamma))\,\}$\;
}
\Return $\mathsf{MerkleRoot}(K)$\;
\end{algorithm}
